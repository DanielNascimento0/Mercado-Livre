# Mercado Livre

Trabalho acadêmico sobre a plataforma Mercado Livre

## Descrição

O Mercado Livre é uma plataforma de comércio eletrônico que permite que usuários comprem e vendam produtos pela internet.

A plataforma pode ser utilizada para pesquisar produtos, realizar compras, anunciar produtos, acompanhar pedidos e realizar pagamentos por meio de serviços integrados à plataforma.

## Público-alvo

O Mercado Livre é destinado principalmente para pessoas que desejam comprar ou vender produtos pela internet.

Alguns exemplos são:

* Pessoas que desejam realizar compras online;
* Pessoas que desejam vender produtos;
* Pequenos e grandes comerciantes;
* Empresas que utilizam a plataforma para comercializar seus produtos;
* Pessoas que procuram diferentes opções de produtos e preços.

## Funcionalidades

As principais funcionalidades do Mercado Livre são:

* Pesquisar produtos;
* Visualizar produtos;
* Comparar preços;
* Comprar produtos;
* Vender produtos;
* Criar anúncios;
* Avaliar produtos e vendedores;
* Adicionar produtos ao carrinho;
* Acompanhar pedidos;
* Consultar histórico de compras;
* Realizar pagamentos;
* Utilizar serviços de entrega;
* Receber recomendações de produtos;
* Salvar produtos de interesse;
* Entrar em contato com vendedores.

## Tecnologias utilizadas

O Mercado Livre utiliza diferentes tecnologias em seus sistemas e aplicações.

Algumas tecnologias utilizadas são:

* Java – utilizada em diferentes sistemas e serviços da plataforma;
* JavaScript – utilizada no desenvolvimento de aplicações web;
* Python – utilizada em sistemas, automação e processamento de dados;
* React – utilizada no desenvolvimento de interfaces;
* Kotlin – utilizada em aplicações e serviços;
* MySQL – utilizada em sistemas que trabalham com bancos de dados;
* APIs – utilizadas para integração entre diferentes serviços e sistemas.

## Requisitos técnicos

O Mercado Livre pode ser utilizado em diferentes dispositivos, desde que possuam acesso à internet e sejam compatíveis com a plataforma.

Computadores e notebooks:

* Windows;
* macOS;
* Linux;
* Navegadores como Chrome, Firefox, Edge, Opera e Safari.

Celulares e tablets:

* Android;
* iOS/iPadOS.

A conectividade com a internet é necessária para acessar a plataforma, pesquisar produtos, realizar compras, acompanhar pedidos e utilizar os demais serviços disponíveis.

O Mercado Livre também disponibiliza aplicativos para dispositivos móveis, permitindo que os usuários realizem compras e acompanhem suas atividades por meio de smartphones e tablets.
